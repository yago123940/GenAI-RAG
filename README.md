# Embeddings
- [Visualizacao](https://projector.tensorflow.org/)

Embeddings são o resultado do treinamento de redes neurais para prever a próxima palavra a ser escrita. Os embeddings são os próprios pesos de treinamento associado a cada palavra. Isso pode ser usado para entender a relação entre as palavras. 

> Word embeddings are the by-product of training a neural network to predict the next word. By focusing on that single objective, the weights themselves (embeddings) can be used to understand the relationships between the words.
